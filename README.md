# Signal Atlas Interactive

Dark UI decision tool skeleton for fusion with the content site (esim.getstylegrab.com).

## What's here
- Dark theme (navy #071421, teal, sunset #e86a2c)
- Homepage: hero "Compare the plan, not the slogan.", destination pills, filters, plan cards with Recheck tag
- Routes: /trip, /dashboard, /install, /saved (placeholders)
- Nav: Compare / Trip / Dashboard / Install / Saved + language

## Fusion rules
- Keep existing /guides/ and /tools/ as static HTML. Do not change their URLs.
- New interactive pages are the main entry.
- Buy buttons use existing Airalo deep links and Saily affiliate link.
- Ranking stays rule-based. Commission does not change order.
- Content pages must stay static HTML for SEO.

This is a starting skeleton. Full recommendation engine, day ledger, 7 languages, and PlaceFrame crossfade to be completed during fusion.
